Install

Running in under a minute.

01

Download

Grab the zip above and unpack it. You'll get Muse.app.

02

Move & open

Drop Muse.app into /Applications, then right-click → Open the first time.

03

Point it at your tools

Muse finds your installed agent CLIs — Claude Code, Codex, and friends — and gives each one a node on the canvas.

The alpha isn't notarized with Apple yet, so on first launch macOS will ask you to confirm: right-click the app, choose Open, then Open again — or allow it under System Settings → Privacy & Security. One time only; updates install themselves.

Muse keeps itself current.
When you're on an older build, Muse shows the new changelog and offers a one-click Download & Restart. Every update is fetched over HTTPS and verified against a signed release manifest — exact SHA-256 and byte count — before a single file is swapped.
